Általános beállítások

Pénznem, minimum kiszállási díj, foglalási előleg, értesítési e-mail.

Ennél kisebb részösszeg esetén ez az összeg számít szolgáltatás-értéknek.
Fix tétel a szolgáltatás-értéken felül, minden foglalásnál. 0 = nincs kiszállási díj.

Szolgáltatások (ügyletformák)

Alap tisztítási tételek. Az „Anyagfüggő" jelölt soroknál a vevő anyagot is választ, és a szorzó módosítja az árat.

Anyagok és szorzók

A szorzó az anyagfüggő szolgáltatások egységárát módosítja (pl. gyapjú = magasabb kockázat és árszorzó).

Foltok / szagok felárai

Három csoport, a beavatkozás nehézsége szerint — így fényképes ajánlatnál is besorolható. Részletek: terepkonyv.html „Foltcsoportok".

Kiegészítő szolgáltatások

Típus: fix = fix összeg; pct = az adott tétel alapdíjának arányos része (pl. 0.5 = 50%).

Vegyszerek (beszerzési referencia)

A tényleges Chemspec-készlet (2026-08-10). ✅ = megvan · 🛒 = beszerzési listán. A „Kiszerelés" oszlop a munkahígítást és behatási időt tartalmazza. Az árakat a számláitokból töltsétek ki.
